# getLogs Suggested Range

This file is kept for compatibility with earlier skill versions.

Use `reference-getlogs-dynamic-bounds.md` as the canonical document.

Key point:

Confura's suggested range feature is primarily exposed through oversized `getLogs` errors such as:

```text
a suggested block range is [...]
a suggested epoch range is [...]
```

It is not necessarily a standalone public JSON-RPC method.
